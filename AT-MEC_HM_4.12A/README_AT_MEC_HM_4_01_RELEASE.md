# AT-MEC_HM_4.01

Bugfix Layout Editor Professional.

## Modifiche
- Pannello Layout elemento reso scorribile.
- Sezioni richiudibili/espandibili: Posizione/Dimensioni, Allineamento/Distanze, Livelli/Blocco/Stile, Testo/Font/Effetti.
- Sezione Testo/Font/Effetti chiusa di default per non occupare lo schermo.
- Base 4.0 mantenuta: font size, font family, colore testo, allineamento, grassetto/corsivo/sottolineato, sfondo, bordo, radius, opacità, padding, ombre, reset stile.

## Nota
Non sono state toccate le funzioni stabili di selezione, dimensionamento, livelli, comandi rapidi e pannello ricerca.
