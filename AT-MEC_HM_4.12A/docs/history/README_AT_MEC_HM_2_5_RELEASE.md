# AT-MEC_HM_2.5

Release stabile successiva ad AT-MEC_HM_2.4.

## Branding integrato di default

- **M_LOGO.png**: logo principale/preview login.
- **MEC.PNG**: logo aziendale.
- **MIRZA_LOGO.png**: logo sviluppatore.

I file sono inclusi in `assets/default_logos/` e caricati automaticamente al primo avvio.

## Layout loghi

- Login: M LOGO grande + MEC piccolo.
- HMI principale: MEC grande + MIRZA piccolo in alto.
- Report PDF: MEC in alto a sinistra, MIRZA in alto a destra.

## Correzioni incluse

- Immagini PNG/WebP/JPG senza sfondo bianco forzato.
- Loghi più grandi e ridimensionati mantenendo proporzioni.
- Layout report corretto per evitare sovrapposizione logo/testo.
- Pulsante Admin per ripristinare i loghi default M/MEC/MIRZA.
- Assets loghi inclusi nel package Electron.

## Nota

La modifica loghi resta disponibile solo per utenti Admin dalla pagina **Loghi HMI / Report**.
