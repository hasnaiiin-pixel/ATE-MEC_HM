# AT-MEC_HM_4.11

Base stabile: AT-MEC_HM_4.10M.

## Modifiche
- Storico Seriali professionale con filtri avanzati: seriale, lotto, operatore, ricetta, esito, data da/a.
- Timeline seriale/test piu leggibile.
- Export CSV storico filtrato.
- Collegamento rapido da Storico Seriali a Scheda Unita.
- Versione interna, titolo applicazione e package aggiornati a 4.11.

## Non modificato
- Test Mode.
- Motore ricette.
- Hardware/strumenti.
- ESP32.
- Layout Editor.
- Login/Utenti.
