# AT-MEC_HM_6.7C_SAFE_DEVICE_MANAGER_ENTERPRISE

Base stabile 6.7B_FIX2D con Device Manager semplificato e sicuro.

- Device Manager semplice: porta, connetti, controlla, salva.
- Nessun watchdog aggressivo.
- Nessuna simulazione automatica.
- Diagnostica PASS solo se il dispositivo risulta ONLINE.
- Test Mode e validazione leggono lo stesso stato condiviso.
- Scheda campione non viene richiesta se il flag è OFF.
