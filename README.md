# AT-MEC_HM_8.0_AI_READY_ENTERPRISE_STABLE

Base pulita: `AT-MEC_HM_7.7.1_AI_APPROVAL_PERSISTENCE_UX`.

Release di consolidamento AI: AI Copilot completo, provider sicuro, approvazioni manuali persistenti, AI Ready Status Center, AI Readiness Score e report finale.

Non crea nuovi moduli Traceability, Repair, Analytics, MES, Factory, Work Orders o Data Contract. AI resta sopra i moduli esistenti e non applica azioni automatiche.

## Avvio

1. Eseguire `INSTALLA_AT_MEC_HM_8.0_AI_READY_ENTERPRISE_STABLE.bat`.
2. Eseguire `AVVIA_AT_MEC_HM_8.0_AI_READY_ENTERPRISE_STABLE.bat`.
