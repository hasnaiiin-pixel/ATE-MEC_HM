# AT-MEC_HM_3.98

Base: AT-MEC_HM_3.97 stabile.

## Modifiche principali

- Aggiunte funzioni Layout Editor:
  - Blocca elemento
  - Sblocca elemento
  - Porta avanti
  - Porta dietro
  - Copia stile
  - Incolla stile
- Gli elementi bloccati non vengono modificati da X/Y/W/H, distribuzione, allineamento e delete.
- Mantenuti i comandi rapidi funzionanti della 3.97.
- Aggiornata versione a 3.98.

## Nota

Versione tecnica di consolidamento: non modifica Test Mode, ricette, ESP32, PL303 o report.
