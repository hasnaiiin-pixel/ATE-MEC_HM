# AT-MEC_HM_4.12J

Base: AT-MEC_HM_4.12I_FIX1 stabile.

Modifica mirata:
- riorganizzazione layout Test Mode;
- pulsanti START / PAUSA / STOP spostati subito sopra la barra avanzamento;
- i pulsanti ESCI TEST MODE e TEST REPORT restano nel pannello laterale;
- nessuna modifica a motore ricette, hardware, report PDF, Data Provider, Sync o Layout Editor.

Prove consigliate:
1. npm install
2. npm run build
3. npm start
4. aprire Test Mode
5. verificare posizione pulsanti START/PAUSA/STOP sopra avanzamento
6. eseguire ricetta PASS/FAIL
