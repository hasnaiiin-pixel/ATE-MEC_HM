# AT-MEC_HM_4.13P_OPERATOR_CENTER

Release basata su 4.13O con miglioramenti richiesti:

- Profilo operatore selezionabile: Admin può vedere Mirza/altri utenti, ruolo, codice, foto e permessi.
- Layout profilo più moderno/social a tutta pagina.
- Permessi leggibili in formato “PUÒ / NON PUÒ” con descrizione.
- Statistiche operatore filtrabili per esito, data e ricerca seriale/ricetta/lotto.
- Fix ruolo utente: dopo refresh non torna da solo a Operator; il ruolo selezionato resta quello salvato.
- Editor ruoli semplificato: se selezioni ruolo esistente, il nome viene rilevato automaticamente e non devi riscriverlo.
- Branding ufficiale: login MIRZA grande + MEC sotto; dashboard/test/report MEC a sinistra e MIRZA a destra.
- Rimozione riferimenti COBO.png non esistente.
- Riduzione polling Layout Editor principale per abbassare warning DevTools setInterval.

Credenziali default:

- admin / admin
- mirza / mirza

Nota: dopo primo avvio puoi cambiare password admin dalla pagina Utenti & Ruoli.
