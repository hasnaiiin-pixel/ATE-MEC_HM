AT-MEC_HM_3.97

Base: 3.96 stabile.

Aggiunti comandi rapidi Layout Editor:
- CTRL+A seleziona elementi visibili della pagina corrente
- CTRL+C copia selezione Layout
- CTRL+V incolla copie con offset
- CTRL+D duplica selezione
- ESC deseleziona
- DEL/BACKSPACE nasconde elementi selezionati, annullabile con CTRL+Z
- CTRL+Z undo
- CTRL+Y / CTRL+SHIFT+Z redo

Layout Editor 3.94/3.96 mantenuto come base.
