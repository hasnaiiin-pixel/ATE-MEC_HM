# AT-MEC_HM_3.34_TEST_LIGHT

Correzioni mirate richieste su Test Mode:

- Switch SN obbligatorio e Test scheda campione spostati a destra dentro il riquadro.
- Header Test Mode adattato all'altezza del tasto EMERGENZA: il pulsante non deve più sbordare fuori.
- Stato esecuzione lampeggiante durante il RUNNING.
- In caso di FAIL con stop step attivo, il test non resta più bloccato a percentuale intermedia: chiude la run, porta avanzamento a 100% e mostra esito finale FAIL.
- Layout Test Mode mantenuto scorribile e più compatibile con altezza finestra.

Versione light senza node_modules.
