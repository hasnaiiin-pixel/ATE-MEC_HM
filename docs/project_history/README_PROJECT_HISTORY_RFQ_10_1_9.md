# Project History / RFQ Tracker — AT-MEC HM / VEXON 10.1.9

Questa cartella contiene il file master da mantenere aggiornato a ogni release:

- `AT_MEC_HM_MAPPA_VERSIONI_RFQ_TEMPI_GRAFICI_10_1_9.xlsx`

Uso previsto:

1. storico versioni e release notes;
2. tempi stimati/consuntivi per RFQ;
3. dashboard grafici;
4. allegato tecnico per richiesta offerta;
5. base di aggiornamento per versioni future.

Regola da seguire a ogni nuova release:

- aggiungere nuova riga in `Versioni Dettaglio`;
- aggiornare `Tempi RFQ` con stima e consuntivo;
- aggiornare dashboard e grafici;
- allineare sempre package.json, BAT, README, config/app_settings.json e src/renderer/js/version.js.

Non inserire password reali, token o credenziali cliente negli allegati RFQ.
