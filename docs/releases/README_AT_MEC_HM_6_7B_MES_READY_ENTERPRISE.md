# AT-MEC_HM_6.7B_MES_READY_ENTERPRISE

Release 6.7B basata su 6.7A stabile.

## Incluso
- Work Orders Enterprise
- Collegamento a Master Data 6.7A
- Produzione collegata a WO
- KPI WO: previsti, prodotti, residuo, yield
- MES Connector Ready: CSV, SQL Server, Access, REST API predisposti
- Import CSV Work Orders
- Export JSON
- Audit Work Orders / MES Ready
- BAT e versione aggiornati a 6.7B
- README precedenti archiviati in docs/releases

## Da provare
1. Aprire app con `AVVIA_AT_MEC_HM_6.7B.bat`.
2. Master Data → Work Orders / MES Ready.
3. Creare o importare un Work Order.
4. Verificare produzione collegata e KPI.
5. Aprire MES Connector e salvare una configurazione.
