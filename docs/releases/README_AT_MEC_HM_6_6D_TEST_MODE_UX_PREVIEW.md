# AT-MEC_HM_6.6D_TEST_MODE_UX_PREVIEW

Release di prova controllata per migliorare la grafica operatore in Test Mode senza modificare il motore di test.

## Incluso

- Action Panel laterale per misura manuale e fallback multimetro.
- Misura manuale moderna con valutazione live della tolleranza quando i limiti sono disponibili.
- Retry multimetro e inserimento manuale più leggibili.
- Badge RETEST protetto e non invasivo, senza spostare il campo S/N.
- Nessuna modifica a Repair Center, SQLite, Repository, Production, Print, Audio o Hardware.

## Da provare

1. Avvio app con `AVVIA_AT_MEC_HM_6.6D.bat`.
2. Test Mode: campo S/N stabile.
3. Step misura manuale: pannello laterale visibile.
4. Inserimento valore: badge dentro/fuori tolleranza.
5. Multimetro non disponibile/fallback: azioni chiare.
6. Seriale in retest: badge non invasivo.

## Note

Questa è una preview UI: se stabile potrà evolvere in una futura schermata Test Mode più moderna.
