# AT-MEC HM 6.8C Analytics Pro

## Obiettivo

Versione dedicata al potenziamento professionale di Analytics Center.

## Modifiche principali

- Analisi PASS con First Pass Yield, seriali unici e controlli passati ricorrenti.
- Analisi FAIL con fail rate, seriali coinvolti, STOP/ABORT e cause ricorrenti.
- Top componenti critici ricavati da campi componente/refdes o note riparazione.
- Top Test Point / Step FAIL.
- Distribuzione misure numeriche con media, min, max e fuori limite.
- Timeline seriali con eventi TEST e REPAIR.
- Dettaglio ultimi FAIL con seriale, ricetta, componente, test point e range misura.
- Filtri aggiunti per commessa/lotto e seriale.
- Report step arricchito con label, componente, test point, device e canale.

## Test consigliati

1. Avviare `AVVIA_AT_MEC_HM_6.8C_ANALYTICS_PRO.bat`.
   In alternativa usare `START_SERVER.bat`.
2. Entrare in `Analytics Center`.
3. Premere `Aggiorna Analytics`.
4. Verificare filtri periodo, commessa, seriale, ricetta, collaboratore e postazione.
5. Eseguire un test PASS e un test FAIL, poi verificare aggiornamento di PASS/FAIL, componenti, test point e timeline seriale.
