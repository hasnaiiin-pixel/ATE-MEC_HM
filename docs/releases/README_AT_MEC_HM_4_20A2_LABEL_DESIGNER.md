# AT-MEC_HM_4.20A2_LABEL_DESIGNER

Versione basata su 4.20A1 Label Manager Fix1.

## Aggiunte
- Label Designer grafico integrato.
- Canvas etichetta con griglia mm logica.
- Elementi: testo, campo dinamico, logo, QR, Barcode, DataMatrix.
- Selezione elemento e pannello proprietà: testo, posizione, dimensione, font, allineamento.
- Drag elementi dentro canvas.
- Duplica / elimina elemento.
- Template PASS, FAIL, REPAIR, LOTTO, CAMPIONE salvati in localStorage.
- Preview live con dati dinamici: seriale, commessa, lotto, operatore, ricetta, firmware, stazione, report ID.

## Non modificato
Login, permessi, Test Mode, Device Manager, Factory, Analytics, Database backend.
