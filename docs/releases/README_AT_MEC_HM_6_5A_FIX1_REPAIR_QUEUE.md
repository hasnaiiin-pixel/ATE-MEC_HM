# AT-MEC_HM_6.5A_FIX1_REPAIR_QUEUE

Fix mirato Repair Center.

## Correzioni
- Rimosso popup automatico durante Test Mode su FAIL.
- Repair Center resta solo nella pagina dedicata sotto Report & QC / KPI.
- Aggiunta FAIL Queue: lista automatica dei seriali con ultimo esito FAIL e senza ticket aperto.
- Apertura ticket dalla FAIL Queue.
- Ticket aperti/storico separati dalla lista FAIL.
- Doppio click su seriale apre Scheda Seriale / Unit Card.

## Cosa provare
1. Eseguire o avere almeno un test FAIL nello storico.
2. Aprire Report & QC / KPI → Repair Center.
3. Premere Aggiorna.
4. Verificare la FAIL Queue.
5. Cliccare Apri Ticket.
6. Compilare difetto, causa, azione, componenti, tecnico.
7. Impostare RETEST/CLOSED.
8. Verificare che Repair Center non appaia in Dashboard o altre pagine.
