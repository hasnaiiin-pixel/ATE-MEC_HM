# AI Menu + Chat Provider UX + Test Mode Cleanup 9.5.2

Questa release consolida la UI senza nuove funzioni business.

## Menu AI semplificato
Le vecchie scorciatoie restano come funzioni interne, ma nel menu principale sono raggruppate in quattro voci:

- Chat AI
- Command Center
- Azioni AI
- Impostazioni AI

## Chat provider UX
La chat mostra sempre se sta lavorando in modalità locale/offline o provider esterno. Il provider esterno richiede conferma prima dell'invio e la API key resta solo in sessione.

## Test Mode
La topbar operatore viene pulita con switch orizzontali e dispositivi rimossi dalla parte alta. Lo stato dispositivi resta nella sezione dedicata Strumenti/Device Manager.
