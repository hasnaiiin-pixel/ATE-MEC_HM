# AI Live Chat 9.3

`AI Live Chat 9.3` rende l'AI visibile nel programma tramite chat integrata dentro la pagina `AI Copilot` esistente.

## Funzioni

- Chat AI visibile con storico conversazione.
- Messaggi AI visibili nel programma.
- Risposta local/offline se il provider non è configurato.
- Invio a provider esterno solo con conferma operatore.
- Copia ultima risposta.
- Export chat JSON senza API key.
- Creazione proposta in `AI Action Queue 9.1` dalla risposta AI.

## Sicurezza

- Nessuna modifica automatica a WO.
- Nessuna modifica automatica a ricette.
- Nessuna modifica automatica a utenti.
- Nessuna modifica automatica a test o hardware.
- API key mai esportata nei report.
- Azioni create solo come proposta manuale in coda.
